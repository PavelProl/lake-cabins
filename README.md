# lake-cabins — «Роща»

Фронтенд сайта реальной базы отдыха у озера Парное в Красноярском крае. Посетитель может посмотреть дома и фотографии, найти базу на карте и связаться с владельцами по телефону или в WhatsApp.

[Открыть демо](https://glistening-muffin-53b0fe.netlify.app/)

## Возможности

- Главная и страницы трёх типов домов: «Усадьба Парная», «Лад», «Тишь и Гладь».
- Анимированное раскрытие карточки в страницу дома и возврат с восстановлением прокрутки и фокуса.
- Галереи 42 фотографий с полноэкранным просмотром, кнопками, клавиатурной навигацией и свайпами.
- Карта, маршрут, ссылки звонка и WhatsApp с названием выбранного дома.
- Адаптивная вёрстка, поддержка уменьшенного движения и звуки природы по желанию.

## Реализация

React, TypeScript, Vite, React Router, GSAP Flip и CSS Modules. Для проверок используются ESLint, Prettier и Playwright.

Приложение работает без бэкенда и базы данных. Данные домов и контакты хранятся отдельно от компонентов. Смена маршрута согласована с анимацией: приложение сохраняет исходный экран до завершения перехода, управляет прокруткой и фокусом. Полноэкранный просмотр фотографий блокирует прокрутку фона и возвращает фокус после закрытия.

```text
src/app/          — маршруты и координация приложения
src/pages/        — главная и страница дома
src/components/   — карточки, галерея, просмотрщик, контакты и звук
src/data/         — сведения о домах, фотографии и контакты
src/transitions/  — переходы, геометрия и управление прокруткой
src/assets/       — подготовленные изображения, шрифты и аудио
tests/            — браузерные сценарии
```

## Локальный запуск

Требуется Node.js 22.22+ в ветке 22 либо Node.js 24+.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Страницы домов: `/houses/large-log-house`, `/houses/medium-house`, `/houses/small-house`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:e2e
```

Для браузерных тестов требуется установленный Google Chrome. Playwright запускает локальный dev-сервер и сценарии для десктопа и эмуляции телефона: переходы и история браузера, галереи, фокус, адаптивность и уменьшенное движение. Эмуляция не заменяет проверку на реальном устройстве.

Просмотр production-сборки после `npm run build`: `npm run preview`. Netlify автоматически собирает `main` командой `npm run build` и публикует `dist`; прямые адреса страниц поддерживаются SPA fallback.

## Статус и ограничения

Это демонстрационная версия, доступная для просмотра, а не завершённый запуск для гостей. Обложки сгенерированы и явно обозначены как концепции; фотографии в галереях предоставлены владельцем.

Оптимизация изображений и скорости загрузки, а также окончательная проверка последних исправлений на реальном телефоне остаются в плане. Индексация намеренно отключена. Цены, вместимость, условия проживания, юридические сведения и права на материалы требуют подтверждения перед запуском для гостей. Онлайн-бронирование и чат-бот не реализованы.
