# lake-cabins — «Домики у озера»

Сайт загородной базы отдыха у озера в Красноярском крае. «Домики у озера» — временное название.

Сейчас доступен локальный React-прототип: карточка большого дома, анимированный переход на страницу дома и обратно, галерея четырёх фотографий. Сайт пока не опубликован.

## Локальный запуск

Требуется Node.js 22.22+ в ветке 22 либо Node.js 24+.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Страница дома: `/houses/large-log-house`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:e2e
```

Для браузерных тестов требуется установленный Google Chrome. Просмотр сборки: `npm run preview`.
