# lake-cabins — «Роща»

Сайт базы отдыха «Роща» у озера Парное в Красноярском крае. Спокойный отдых на природе у озера.

Подготовлена версия для демонстрации владельцам: главная, три типа домов, галереи 42 фотографий, контакты, карта, звуки природы по желанию и анимированные переходы. Обложки обозначены как концепции. [Демо опубликовано на Netlify](https://glistening-muffin-53b0fe.netlify.app/); индексация отключена. Перед запуском для гостей требуется уточнить юридические сведения и оставшиеся данные из брифа.

## Локальный запуск

Требуется Node.js 22.22+ в ветке 22 либо Node.js 24+.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Страницы домов: `/houses/large-log-house`, `/houses/medium-house`, `/houses/small-house`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:e2e
```

Для браузерных тестов требуется установленный Google Chrome. Просмотр сборки: `npm run preview`.
