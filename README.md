# lake-cabins — «Домики у озера»

Сайт загородной базы отдыха у озера в Красноярском крае. «Домики у озера» — временное название.

Сейчас доступен локальный React-прототип: полноэкранная обложка главной, три карточки и страницы типов домов, анимированный переход и возврат, галереи 42 фотографий с полноэкранным просмотром (9 / 19 / 14). Обложки обозначены как концепции. Сайт пока не опубликован.

## Локальный запуск

Требуется Node.js 22.22+ в ветке 22 либо Node.js 24+.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Страницы домов: `/houses/large-log-house`, `/houses/medium-house`, `/houses/small-house`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run test:e2e
```

Для браузерных тестов требуется установленный Google Chrome. Просмотр сборки: `npm run preview`.
